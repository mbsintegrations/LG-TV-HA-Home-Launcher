# Screenshot gallery

Actual browser renders of the TV app using fictional sample readings. The same apps, logo appearance, controls and cards are used throughout so you can compare only the layout and colours. Click any image for the full-size screenshot.

There are **24 combinations across the four new themes and six presets**, plus six Classic combinations. Custom colours are unlimited; five additional images show one example custom palette, one per layout.

[Dock](#dock) · [Weather](#weather) · [Sidebar](#sidebar) · [Panorama](#panorama) · [Classic](#classic) · [Custom examples](#custom-examples) · [Configurator screenshots](CONFIGURATOR-TOUR.md)

Choose these in **Your space → Layout theme** and **Color Palette**. See [themes and colours](THEMES.md) for a guide.
