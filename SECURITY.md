# Security reporting

Do not post HA tokens, private IPKs, pairing keys, passphrases or unredacted household configuration in a public issue. A configured package contains an extractable HA token.

Use this repository's private vulnerability-reporting option when available. If it is unavailable, open an issue asking for a private contact route without exploit details or secrets. Do not use the donation button to send sensitive information.

This is an experimental preview with no production support guarantee. Fixes target the latest preview. The optional legacy Home-button helper has additional native-input and dependency risks and must be assessed separately from the base app. Read [the security model and credential lifecycle](docs/SECURITY.md) before installation.
